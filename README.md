# Дневник тренировок — Android

Приложение для локального учёта силовых тренировок. Записи сохраняются на устройстве в SQLite.

## Возможности
- выбор даты тренировки;
- упражнения: жим штанги, приседания, жим гантелей, бицепс и другие;
- количество подходов, повторений и рабочий вес;
- история тренировок;
- удаление записи с подтверждением.

## Получение APK
Сборка запускается автоматически через GitHub Actions после загрузки кода. Откройте вкладку **Actions**, выберите успешный запуск **Build Android APK**, затем скачайте артефакт **WorkoutJournal-debug-apk**. Внутри ZIP будет файл `app-debug.apk`.

Требования: Android 6.0 и новее. Интернет нужен для загрузки приложения; журнал тренировок хранится локально на устройстве.
